{# F9.3 — Named codebook snapshots panel. A snapshot is a named, dated, immutable bookmark of the entire codebook ("Initial coding done 2026-04-12") so any future report can be regenerated against it. The pure module ``scribe.codebook_snapshots`` shipped in 33d3981 with full validation, atomic save, and an F9.1 audit-event emission. Until this panel + the four ``/api/projects//snapshots`` routes landed, the only way to take or list a snapshot was via Python. Reads: GET /api/projects//snapshots — list POST /api/projects//snapshots — create GET /api/projects//snapshots/ — single GET /api/projects//snapshots//codebook?format=... — render the codebook *as it stood at* this snapshot (CSV / Markdown / RTF). Used by the per-row download links. #}

Codebook snapshots

A snapshot freezes the entire codebook (every code + each code's pinned definition version) under a chosen name. Use it to mark methodological milestones — "Initial coding done", "Before unlocking", "Submission draft" — so any later report can be regenerated against that bookmark. Snapshots are immutable; once taken they can never be edited or deleted.

Suggestion surfaces

These F-features are wired in their natural location. The dashboard view that aggregates pending suggestions across the project will graduate here as F8.6 + F8.7 land their UI.

  • Suggest existing code on a span (F8.3) — open a transcript and use the "✨ Suggest existing code with AI" row in the apply-popover on a highlight.
  • Propose a new code on a span (F8.4) — separate command in the apply-popover: "✨ Propose a new code with AI". Picking a proposal creates the :class:`Code`, applies it to the span, and stamps AI provenance (feature=new_code_suggestion). Pending and rejected proposals are kept as audit rows under /ai/new-code-suggestions per F9.6.
  • Find similar quotes (F8.5) — per-application action on the source-coding view: open a transcript with at least one coded segment and click the "🔎 Find similar quotes" button on any .app-row. The ranked list comes back from POST /ai/quote-searches and is logged for the F9.6 audit trail. No LLM call — pure embedding-space nearest-neighbour search over the F8.2 index, so this is the safest of the AI features.
  • Whole-transcript review pass (F8.6) — background job; result list will surface here. queue UI pending
  • AI second coder (F8.7) — runs on a locked codebook; ICR + diff will surface here. queue UI pending
  • Memo drafting (F8.8) — "✨ Draft with AI" action on a memo (lands with the memos page graduations).
